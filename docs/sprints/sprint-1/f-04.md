### 5.2 Behaviour

- Only the owner of a survey can view its summary.
- A respondent, or another owner, receives `403` with no summary data.
- The summary reports:
  - `totalResponses` — number of response rows for the survey.
  - Per question: `answeredCount`, option counts and percentages.
  - Short- and long-text answers as unlinked lists of strings.
  - Rating and integer count, average, minimum and maximum (Sprint 2).
  - Date answer counts grouped by calendar date (Sprint 2; F-06 Issue [#9](https://github.com/Snnn3/SurveyHub/issues/9)).
- Percentage denominator is `answeredCount` for that question, not `totalResponses`. This is correct
  when a question is optional and some respondents skip it.
- For multi-choice, each option percentage is the share of answerers selecting that option; totals
  may exceed 100% because one answer can select several options.
- Percentages are rounded to two decimals.
- No respondent name, email, user id or response id appears in the summary payload.
- A survey with zero responses returns zero counts and empty lists, not an error.

### 5.3 UI behaviour

**`/owner/surveys/:id/summary`**

- Header: title, description, status badge, created date.
- KPI card: total responses.
- For each question:
  - Single-choice, multi-choice, yes/no and Likert: option label, progress bar, count and percentage.
  - Short and long text: list of unlinked answers, or "No text answers yet."
  - Rating (Sprint 2): average and distribution across 1–5.
  - Integer (Sprint 2): count, average, minimum and maximum.
  - Date (Sprint 2): count by calendar date.
- Empty state when `totalResponses = 0`: "No responses submitted yet."
- Loading skeleton and error banner.
- Access denied page for 403 without rendering any data.

### 5.4 Data specification

Read-only aggregation over `survey_responses`, `answers`, `answer_options`, `options` and `questions`.
F-06 supplies the typed answer fields; aggregation queries are scoped by `surveyId` and authorized by
`ownerId`.

Percentage formula:

```text
percentage = answeredCount > 0 ? round(optionCount / answeredCount * 100, 2) : 0
```

### 5.5 API specification

#### GET `/api/surveys/:id/summary`

Success `200`:

```json
{
  "success": true,
  "data": {
    "surveyId": "<uuid>",
    "title": "CPE 334 Midterm Feedback",
    "status": "PUBLISHED",
    "mode": "IDENTIFIED",
    "totalResponses": 15,
    "questions": [
      {
        "questionId": "<uuid-1>",
        "prompt": "How satisfied are you with the course?",
        "questionType": "SINGLE_CHOICE",
        "answeredCount": 15,
        "options": [
          { "optionId": "<uuid-opt-1>", "label": "Very satisfied", "count": 10, "percentage": 66.67 },
          { "optionId": "<uuid-opt-2>", "label": "Neutral", "count": 4, "percentage": 26.67 },
          { "optionId": "<uuid-opt-3>", "label": "Unsatisfied", "count": 1, "percentage": 6.67 }
        ]
      },
      {
        "questionId": "<uuid-2>",
        "prompt": "What should improve?",
        "questionType": "SHORT_TEXT",
        "answeredCount": 8,
        "textAnswers": ["More lab time, please.", "Clearer grading rubric."]
      }
    ]
  }
}
```

Errors:

- `403 FORBIDDEN_ROLE` — respondent.
- `403 FORBIDDEN_OWNERSHIP` — another owner.
- `404 NOT_FOUND` — unknown survey.

### 5.6 Acceptance criteria

| AC | Observable outcome |
|---|---|
| **AC-F04-01** | Counts, percentages and text answers match the database; percentages use `answeredCount` and are rounded to two decimals; no respondent identity field is present. |
| **AC-F04-02** | A respondent receives `403 FORBIDDEN_ROLE` and no summary data. |
| **AC-F04-03** | A non-owner owner receives `403 FORBIDDEN_OWNERSHIP` and no summary data. |
| **AC-F04-04** | A survey with zero responses returns `totalResponses = 0`, zero counts, empty text lists and `200`. |
